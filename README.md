# AplicacionesMoviles
En este repositorio se publicaran los proyectos que llevemos a cabo en la materia de Desarrollo de Aplicaciones Móviles 

Rama "**MicroProyecto_1**"
En esta rama se publico el primer proyecto que realizamos usando el framwork Ionic, el cual consiste en una lista de tareas que mandamos llamar para que en consola nos muestre las tareas que tenemos pendientes

Rama "**MicroProyecto_1_Actualizacion**"
En esta rama se publico la primera actualizacion del proyecto, donde agregamos componentes como inputs, labels, buttons y list

Rama "**MicroProyecto_1_Actualizacion2**"
En esta rama se publico la segunda actualizacion de proyecto, donde creamos una carpeta nueva llamada "pages" y agregamos dentro toda nuestra capreta "home", posteriormente agregamos y importamos componentes nuevos como iconos 

Rama "**Parcial1_ToList**"
En esta rama se publico el primer proyecto parcial que es el programa de lista de tareas, actualizado para que cumpla con los siguientes requisitos: **titulo no vacio, no tareas duplicadas, sensible a mayusculas y minisculas, para finalizar con espacios en blanco antes y despues**
