# AplicacionesMoviles
En este repositorio se publicaran los proyectos que llevemos a cabo en la materia de Desarrollo de Aplicaciones Móviles 

Rama "**ProyectosAngular**"
En esta rama se publicaron los tres proyectos que trabajamos usando el framework Angular las primeras 2 semanas de clases. Las actividades realizadas son las siguientes: 
- Desarrollo de un formulario en Angular (Fecha de la actividad - 07/05/2026)
- Desarrollo de proyecto utilizando cards (Fecha de la actividad - 11/05/2026)
- Tarea: desarrollo de proyecto Login y Menu (Fecha de la actividad - 14/05/2026)

Rama "**MicroProyecto_1**"
En esta rama se publico el primer proyecto que realizamos usando el framwork Ionic, el cual consiste en una lista de tareas que mandamos llamar para que en consola nos muestre las tareas que tenemos pendientes
